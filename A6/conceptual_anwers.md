## 1. What is refactoring? Give three examples of refactoring techniques.

Refractoring is the process of rewriting/reorganizing code such that it is easier to understand or works more efficiently. 

Refractoring techniques include: renaming variables/funcions, organizing/moving functions to different scripts, and rewriting algorithms to run faster or be more readable.

# 2. In a data science project, why does code naturally go through “phases” of messiness?

Usually you start by exploring the data and coding to get a working prototype. This phase is often quite messy. Later when things start working, usually you clean it up so that your code is more understandable.

# 3. What are three techniques for creating more modular code?

Break your code down into functions, organize your code into classes, and group similar functions in different files.
